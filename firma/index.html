Step 03 — Install it

Paste it into Outlook

  1. Open Outlook on the web (outlook.office.com) and sign in with your Fausto account.
  2. Click the gear icon (top right) → Accounts → Signatures.
  3. Delete any signature already there. Select all the old content and clear it — otherwise you end up with two signatures stacked.
  4. Click Copy signature above, then paste here with Ctrl + V (Cmd + V on Mac).
  5. Turn on "Automatically include my signature on new messages" and "on messages I forward or reply to". Then Save.
  6. Send yourself a test email. Reply to it too — check the signature shows up both times.
  1. Do the web version first. If your desktop Outlook syncs signatures from the cloud, it may already be done — check before repeating the work.
  2. In Outlook, go to File → Options → Mail → Signatures. (New Outlook: Settings → Accounts → Signatures.)
  3. Delete every old signature in the list, not just the default one.

  5. Set it as the default for New messages and for Replies/forwards. Click OK.
